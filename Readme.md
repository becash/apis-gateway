A minimal Go HTTP service that showcases an OpenAPI-first workflow. It serves a simple read-only endpoint to fetch an item by ID, publishes the OpenAPI spec, and provides an interactive Swagger UI for exploration. The server listens on port 8080, exposes the spec at /openapi.yaml, and hosts documentation at /docs. This is intended as a lightweight example of wiring a generated router to a handler and shipping self-hosted API docs with zero extra tooling.
